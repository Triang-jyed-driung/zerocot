# zerocot
My Zero CoT

## Usages:

1. Run `construct_corpus.py` for some corpus
2. Use json2binidx tool to convert it to `examples.bin/idx`
3. train a model on `examples.bin/idx` to get used of cot examples: Use https://github.com/Triang-jyed-driung/my-pretrain
4. run the training script on normal corpus (not dummy examples)
